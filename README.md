# 🏃‍♂️ Tag You're It

**Tag You're It** is a multiplayer tag game developed using Unity and Photon PUN. Players engage in real-time gameplay to catch each other and become "it," creating an interactive and fun gaming experience.

## 🎮 Game Features

- **Multiplayer Gameplay**: Real-time multiplayer support using Photon PUN.
- **Simple and Fun Mechanics**: One player is designated as “it” and tries to tag the others, while the other players hide and attempt to tag the “it” player to reverse the roles. The goal is to avoid being “it” for as long as possible.
- **Real-Time Synchronization**: Seamless synchronization of player movements and interactions.
- **Easy to Start**: Quickly jump into the game and play with friends.

## 🛠️ Technologies Used

- [Unity](https://unity.com/)
- [Photon Unity Networking (PUN)](https://www.photonengine.com/pun)
- C#
